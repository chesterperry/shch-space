# Решение: убрать записи и магазин из публичного сайта

- Дата: 2026-09-07
- Статус: опубликовано и проверено в runtime
- Область: `shch.one`, репозиторий `shch-space`

## Причина

Владелец запросил убрать разделы «Записи» и «Магазин» из опубликованного сайта.

## Baseline

- Действующий production release:
  `ddb749dbe85874786b85cc80992f3543491166fa`.
- До изменения главная ссылалась на `/notes/` и `/shop/`, а сборка содержала
  список записей, страницы отдельных записей и страницу магазина.

## Решение

- Удалить ссылки «ЗАПИСИ» и «МАГАЗИН» с главной.
- Удалить публичные Astro-маршруты `/notes/`, `/notes/<slug>/` и `/shop/`.
- Не удалять исходные Markdown и изображения записей из Obsidian или
  версионируемого content snapshot.
- Не менять главную, страницы проектов, аналитику, canonical и Astro-архитектуру.

## Откат

При необходимости повторно опубликовать release
`ddb749dbe85874786b85cc80992f3543491166fa`.

## Принятие

Технический критерий: главная и проекты отвечают `200`, а `/notes/`,
`/notes/london-2013/` и `/shop/` отвечают `404`.

## Проверка кандидата

- `pnpm check`: 0 ошибок, предупреждений и замечаний.
- `pnpm build`: 8 статических страниц и 17 оптимизированных изображений.
- Полный dependency audit: известных уязвимостей нет.
- Локально главная и проекты отвечают `200`; удалённые разделы отвечают `404`.

## Результат релиза

- Release commit:
  `4793743d09b34998603984f97af05ad040cc4065`.
- GitHub Pages workflow `34146787945` завершился успешно.

- Главная и проектные маршруты отвечают `200`.
